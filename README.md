## 🌟 What is FitGuide Pro?

**FitGuide Pro** is a fully responsive, feature-rich fitness web application built with pure **HTML, CSS, and JavaScript** — no frameworks, no dependencies, no backend. Everything runs right in your browser.

Whether you're a gym newbie or a seasoned athlete, FitGuide Pro gives you:
- 🔢 Smart health calculators
- 🥗 Personalised diet plans
- 🏋️ Structured workout programs
- 📊 A progress tracker
- 💡 Evidence-based fitness tips

All in one sleek, beautiful interface.

## 🛠️ How to Use

### ▶️ Option 1 — Open Directly (Easiest)

```bash
# 1. Download or clone the repository
git clone https://github.com/Yashkumar07-cyber/gym-fitpro.git

# 2. Navigate into the folder
cd gym-fitpro

# 3. Open index.html in your browser
# Just double-click index.html  OR  right-click → Open with browser
```

> ✅ No installation needed. No npm. No build tools. It just works!

---

### 🌐 Option 2 — Use Live Server (Recommended for development)

If you use **VS Code**:

1. Install the **Live Server** extension
2. Right-click on `index.html`
3. Select **"Open with Live Server"**
4. Your browser opens at `http://127.0.0.1:5500`

---

### 🧭 Navigating the App

| Section | What to do |
|---------|-----------|
| **BMI** | Enter your height (cm) and weight (kg) → Click "Calculate BMI" |
| **Calories** | Fill age, gender, height, weight, activity level → Click "Calculate Calories" |
| **Diet** | Click Weight Loss / Maintenance / Weight Gain tabs to switch meal plans |
| **Exercises** | Click muscle group filter buttons (Chest, Back, etc.) to filter |
| **Workouts** | Click Beginner / Intermediate / Advanced to switch program |
| **Water** | Enter weight and activity level → Click "Calculate" |
| **Tracker** | Enter date, weight, notes → Click "Save Entry" |
| **Tips** | Click "Next Tip →" to cycle through fitness tips |
| **Contact** | Fill the form and hit "Send Message" |
